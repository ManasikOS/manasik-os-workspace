# Progress & Verification Records

Point-in-time snapshots: phase verification reports, progress checkpoints,
and similar records written *during* or *after* a build to record what was
checked and what the state was at that moment.

These are historical records, not living specs — don't edit them to match
later reality. If the underlying design changed, update the module's doc
under [`docs/modules/`](../modules/) instead, and leave the snapshot here
as-is (it documents what was true when it was written).
